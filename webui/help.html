INI ⇄ Excel 转换工具帮助

用于 Warcraft III table 物编数据与 Excel 工作簿互转。

基本流程

  1. 选择转换类型：INI → Excel 或 Excel → INI。
  2. 选择输入路径。INI 导出支持单个 .ini 文件或 table 目录；Excel 回写请选择 .xlsx 文件。
  3. INI 导出需要选择输出位置并填写输出文件名；Excel 回写默认使用工作簿记录的原始 INI 路径。
  4. 点击“开始转换”。转换成功后可在主界面打开输出位置。

INI → Excel

  • 选择地图目录时，如果目录下同时存在 table 与 w3x2lni，程序会自动进入 table 子目录。
  • 工具会跳过 imp.ini、w3i.ini、misc.ini 这类非物编表。
  • 多等级数组会被整理到同一个单元格；设置中启用公式识别后，等差数列会显示为 calc@10+5 形式。

Excel → INI

  • 由本工具导出的 Excel 会记录每个工作表的原始 INI 路径，回写时默认覆盖这些原始文件。
  • 如果关闭“回写到原始 ini 文件”，工作簿会按工作表名称生成到指定 table 目录。
  • 默认工作表映射：技能 → ability.ini、魔法效果 → buff.ini、物品 → item.ini、单位 → unit.ini、科技 → upgrade.ini。
  • 单元格里使用独立一行 ---- 可以分隔多等级文本。
  • levels 大于 1 时，常见等级字段会回写为 {...} 数组；calc@A+B 会按等级数展开。
  • 包含换行的文本会回写为 [=[...]=]，避免破坏 Warcraft III 文本格式。

w2l 拆包与装包

  • 如果要直接选择 .w3x 地图文件，请先安装 w3x2lni。
  • 在主界面右上角“设置”里选择 w2l.exe；也可以选择 w3x2lni.exe，程序会尝试使用同目录下的 w2l.exe。
  • “拆包地图”会调用 w2l.exe unpack，并把生成的 table 目录填入 INI 导出输入路径。
  • “装包地图”会调用 w2l.exe pack，把拆包目录重新输出为 .w3x。
建议每次批量回写前保留原始 table 目录备份，尤其是在大规模修改技能或单位数据时。
